# Supermarket Management System

Academic C project implementing a supermarket management system with customer management, product management, shopping cart operations, and persistent data storage.

## Features

- Customer management
- Product management
- Shopping cart operations
- Binary file persistence
- Compressed binary storage support
- Product sorting and searching
- Dynamic memory management

## Technologies

- C
- Dynamic Memory Allocation
- Linked Lists
- File I/O
- Modular Programming

## Project Structure

The project is divided into multiple modules responsible for:

- Customers management
- Products management
- Shopping cart handling
- Binary and compressed file operations
- Utility and helper functions

## Running the Project

1. Open `HW3_Solution.sln` in Visual Studio.
2. Build the solution.
3. Run the application.
4. Create a new supermarket or load existing data from binary files.
5. Manage products, customers, and shopping carts through the application menu.

## Learning Objectives

This project was developed as part of an academic software engineering course and demonstrates:

- Dynamic memory management
- Linked list usage
- Binary file handling
- Data organization and modular design
- Search and sorting algorithms
- Structured C programming

## Project Type

Academic software development project focused on data structures, memory management, file handling, and modular programming in C.
